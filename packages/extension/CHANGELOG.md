# Changelog

All notable changes to Structurizr Visualizer are documented in this file.

## 0.0.2

- Renamed the extension from Structurizr Studio to Structurizr Visualizer.
- Redesigned the Marketplace presentation with a clearer product description, visual feature overview, badges, examples, support information, and an explicit compatibility table.
- Improved extension discovery metadata and added the project author.
- Rebuilt the installable VSIX with the bundled icon, license, README, and changelog.

## 0.0.1

- Added Structurizr DSL syntax highlighting, parsing, completion, validation, and Go to Definition.
- Added local file, directory, and nested `!include` support.
- Added standalone model, view, relationship, and style fragments.
- Added cross-file flat and hierarchical identifier resolution and completion.
- Added relative path completion for includes, workspace extension, documentation, ADRs, icons, and themes.
- Added Structurizr DSL 6.2.3 style properties, values, shapes, and color syntax.
- Added line and block comment support.
